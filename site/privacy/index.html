Privacy Policy

Updated 30 October 2026

In short: RecovMe doesn’t collect anything about you. The app has no account, no analytics and no tracking, and your files never leave your computer. This website has no cookies, no analytics and no ads.

The RecovMe app

  • Your files and scans stay on your computer. RecovMe reads the drive, phone or backup you choose and saves the results to a folder you choose. Nothing is uploaded.
  • No account, no analytics, no crash reports. RecovMe doesn’t send usage data anywhere.
  • Update check. To tell you about new versions, RecovMe asks GitHub whether a newer version exists, and downloads it from GitHub when you choose Update and Restart. GitHub sees that request, like any visit to a website. You can turn the check off under Check for Updates at the bottom of the sidebar.
  • Phones. Android phones are read over the USB cable on your computer. iPhone and iPad backups are read on your computer. The password of an encrypted backup is only used in memory during the scan and is never saved.
  • Links. RecovMe only opens a website (such as recovme.app, GitHub or the optional PayPal donation page) when you click a link to it.

This website

  • Hosting. recovme.app is hosted by GitHub Pages. Like any web host, GitHub may record technical data such as IP addresses to run and protect the service; see the GitHub privacy statement.
  • No cookies, analytics or trackers. The site doesn’t set cookies and doesn’t use analytics, ads or social media widgets. Fonts are served from recovme.app itself.
  • Download buttons. To link straight to the newest installer, the download buttons ask GitHub’s public API for the latest release, from your browser.
  • Donations. The “Buy Me a Coffee” button and QR code open PayPal. PayPal’s own privacy policy applies there; I only receive what PayPal shows to the recipient of a payment.

Your rights and contact

Because RecovMe and this website don’t collect personal data, there is nothing stored by me to access, correct or delete. For data held by GitHub or PayPal, contact them directly. For any question about this policy, open an issue on GitHub.

This page is written in plain language and is not legal advice. If anything changes, this page and its date will be updated.
