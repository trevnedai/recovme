Vos chances : cela dépend du disque

Sur un disque dur, les fichiers supprimés restent généralement jusqu’à ce que l’espace soit réutilisé : les chances sont donc bonnes. Sur un SSD, présent dans la plupart des portables et des PC récents, Windows demande au disque d’effacer les fichiers supprimés, généralement en quelques minutes. Dans ce cas, les options gratuites de Windows ci-dessous sont votre meilleure chance.

Regardez d’abord dans ces endroits gratuits

  • Corbeille. Ouvrez-la sur le bureau, faites un clic droit sur le fichier et choisissez Restaurer.
  • Corbeille de OneDrive. Si le dossier est synchronisé avec OneDrive, connectez-vous sur onedrive.com et ouvrez la Corbeille. Avec un compte Microsoft personnel, les fichiers supprimés y restent 30 jours.
  • Versions précédentes. Faites un clic droit sur le dossier où se trouvait le fichier, choisissez Propriétés, puis l’onglet Versions précédentes. Des copies apparaissent si l’Historique des fichiers ou les points de restauration étaient activés.
  • Historique des fichiers. Si vous l’avez configuré avec un disque de sauvegarde, ouvrez Panneau de configuration › Historique des fichiers › Restaurer des fichiers personnels.

Disque dur ou SSD ?

Appuyez sur Ctrl + Maj + Échap pour ouvrir le Gestionnaire des tâches, choisissez Performances, puis cliquez sur votre disque. Le type, SSD ou HDD, s’affiche à droite.

Votre disqueVos chances
HDD (disque dur)Bonnes, à condition d’arrêter d’utiliser le PC pour autre chose. Un PC allumé écrit sans arrêt sur son propre disque.
SSDFaibles. Les noms de fichiers peuvent subsister, le contenu rarement. RecovMe peut quand même essayer et vous indique quels fichiers récupérés sont vides.
Les fichiers étaient sur une clé USB, une carte SD ou un disque externeGénéralement bonnes. Voir le guide des cartes SD ou le guide des disques externes.

Avant l’analyse

  • N’utilisez plus le PC pour autre chose : pas de téléchargements, pas de mises à jour, pas de nouveaux fichiers.
  • Préparez une clé USB ou un disque externe. RecovMe n’enregistre rien sur le disque analysé : sur un PC à un seul disque, il vous faut donc un autre endroit pour les fichiers.
  • Pour les fichiers qui comptent vraiment, le plus sûr est de retirer le disque dur, de le brancher sur un autre ordinateur avec un adaptateur USB et de l’analyser là.

Récupérez les fichiers en 6 étapes

RecovMe est gratuit jusqu’au bout : pas d’essai, pas de limite de taille, rien à payer avant d’enregistrer. L’application est en anglais : les noms des boutons sont donc indiqués tels que vous les verrez.

  1. Téléchargez et ouvrez RecovMe

    Il fonctionne sous Windows 10 et 11 (64 bits). Si une fenêtre bleue SmartScreen apparaît, choisissez Informations complémentaires puis Exécuter quand même. Autorisez-le à apporter des modifications quand Windows le demande : il a besoin des droits d’administrateur pour lire le disque directement.

  2. Choisissez le disque

    Choisissez dans la liste de gauche le disque où se trouvaient les fichiers, généralement C:.

  3. Choisissez quoi chercher

    Photos, Videos et Documents sont cochés par défaut. Ajoutez Music & Audio ou Archives si besoin. Moins de types rendent l’analyse plus rapide.

  4. Gardez Smart Scan

    Smart Scan lit d’abord la table des fichiers du disque, ce qui, sur les disques Windows (NTFS), récupère les fichiers supprimés récemment avec leurs noms et dossiers d’origine. Ensuite, il cherche le reste dans chaque bloc.

  5. Enregistrez sur votre clé USB ou disque externe

    Sous Save Recovered Files To, choisissez un dossier sur l’autre disque. Évitez les dossiers OneDrive ; RecovMe vous prévient si vous en choisissez un.

  6. Lancez l’analyse et ouvrez vos fichiers

    Cliquez sur Start Scan, puis sur Open Recovered Files une fois terminé. Les fichiers qui ont gardé leur nom sont dans Original names ; le reste est trié par type.

Questions

J’ai utilisé Maj + Suppr. Les fichiers peuvent-ils revenir ?

Maj + Suppr contourne la Corbeille : le résultat est le même que si vous l’aviez vidée. Sur un disque dur, les fichiers restent généralement jusqu’à ce que l’espace soit réutilisé. Sur un SSD, ils sont généralement effacés peu après.

Mon PC ne démarre plus. Puis-je récupérer mes fichiers ?

Si le PC a un disque amovible, branchez-le sur un autre ordinateur avec un adaptateur USB et analysez-le là. Beaucoup de portables fins ont un SSD soudé : dans ce cas, mieux vaut passer par un réparateur.

Pourquoi a-t-il besoin des droits d’administrateur ?

Lire l’espace supprimé, c’est lire le disque directement, sous les fichiers et dossiers qu’affiche Windows. Windows ne l’autorise qu’aux applications exécutées en tant qu’administrateur. RecovMe ne fait que lire ; il n’écrit jamais sur le disque analysé.

RecovMe est-il vraiment gratuit ?

Oui, à 100 %. Pas d’essai, pas de limite de taille, rien à débloquer après l’analyse. Il est open source, et les dons sont facultatifs.

Envoie-t-il mes fichiers quelque part ?

Non. Tout se passe sur votre ordinateur. RecovMe n’a ni compte, ni cloud, ni pistage.
