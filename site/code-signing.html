RecovMe

Code Signing Policy

Every RecovMe download is built automatically from the public source code on GitHub and signed, so your computer can check that it really comes from RecovMe and hasn't been changed.

Windows

Free code signing provided by SignPath.io, certificate by SignPath Foundation.

Status: RecovMe has applied to the SignPath Foundation program. Windows releases are signed as soon as the application is approved.

Only installers built by RecovMe's public GitHub Actions workflow from the trevnedai/recovme repository are submitted for signing, and each release is approved by hand before it is signed.

Mac

The Mac app is signed with an Apple Developer ID and notarized by Apple, so macOS confirms it before it opens.

Team and Roles

  • Committers and reviewers: Dhan Denvert Asuncion
  • Approvers: Dhan Denvert Asuncion

Changes from outside contributors are reviewed before they are merged. All team accounts use two-factor authentication.

Privacy

This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it.

RecovMe has no account, no analytics and no tracking. The scan and the recovered files stay on your computer. The app only opens a web page (such as the optional PayPal donation page or the GitHub project) when you click a link to it.

Included Components

RecovMe bundles two open-source recovery engines, distributed unchanged under their own licenses: PhotoRec by CGSecurity (GPL) and The Sleuth Kit.
