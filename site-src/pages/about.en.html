Who makes RecovMe

RecovMe is made by Dhan Denvert Asuncion, an independent developer. I write the app, the website and the guides, and I sign every Mac release with my own Apple Developer ID: “Dhan Denvert Asuncion (GH6TUBY83F)”.

I built RecovMe because losing photos and files is stressful enough without being asked to pay just to get them back. Most “free” recovery apps scan for free and then charge to save what they found. I wanted one that is simple, honest about what it can and can’t do, and free all the way.

How RecovMe works

RecovMe doesn’t invent its own recovery method. It runs two respected open-source engines and does the tidy-up work around them:

  • The Sleuth Kit, by Brian Carrier and contributors, brings back recently deleted files with their original names and folders.
  • PhotoRec, by Christophe Grenier (CGSecurity), finds more than 480 file types by their content, even after a format.
  • For Android phones it uses Google’s own adb tool; for iPhones and iPads it reads the backups on your computer.

RecovMe then sorts the results, names photos and videos by the date they were taken and removes duplicates. It only reads the drive you scan and never saves onto it.

How you can trust your copy

  • Open source. Every line of code is public on GitHub, under the GPL-3.0 license.
  • Built in public. Releases are built by GitHub Actions from that source code.
  • Signed. The Mac app is signed and notarized by Apple. Windows signing through the SignPath Foundation program is being set up; see the code signing policy.
  • Checksums. Each release lists SHA-256 checksums in SHA256SUMS.txt, so you can check that a download is the official one.
  • Signed updates. RecovMe refuses any update that isn’t signed with its own key.
  • One official source. Get RecovMe only from recovme.app or its GitHub Releases page. The name and logo are protected so that copies can’t pretend to be it (name and logo policy).

Contact
