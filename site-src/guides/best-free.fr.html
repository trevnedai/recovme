Réponse courte

La plupart des logiciels de récupération « gratuits » vous laissent analyser gratuitement, puis limitent ce que vous pouvez enregistrer à 100 Mo, voire 2 Go. Seuls quelques-uns n’ont aucune limite : PhotoRec, Windows File Recovery de Microsoft et RecovMe, plus quelques outils gratuits limités à certains fichiers ou disques. Le tableau complet, vérifié sur le site de chaque éditeur, se trouve ci-dessous.

Lequel choisir ?

  • Mac à puce Apple, et vous voulez une application normale : RecovMe. Sur Mac, c’est le seul de cette liste qui récupère sans limite et sans passer par le Terminal.
  • Linux ou un Mac Intel : PhotoRec.
  • Windows, et la ligne de commande ne vous fait pas peur : Windows File Recovery, de Microsoft.
  • Windows, fichiers supprimés il y a quelques minutes d’un disque dur : Recuva ou le Quick Scan de RecovMe, qui gardent tous deux les noms d’origine.
  • Un disque qui fait des clics, n’est pas détecté ou se déconnecte : aucun. Débranchez-le et faites appel à un laboratoire de récupération de données si les fichiers comptent.

Ce qu’aucune application, gratuite ou payante, ne peut faire

Aucune application ne peut ramener des fichiers supprimés du SSD interne d’un portable récent ou d’un Mac à puce Apple : le disque les efface lui-même, et les Mac le chiffrent en plus. C’est pareil pour les téléphones : seules les copies qui existent encore, dans une corbeille, une application de messagerie ou une sauvegarde, peuvent revenir. Méfiez-vous de toute application qui promet le contraire. Sur ces appareils, regardez d’abord la Corbeille, Time Machine, l’Historique des fichiers, OneDrive, iCloud ou Google Photos.

Questions

Pourquoi tant de logiciels de récupération « gratuits » ont-ils une limite ?

La version gratuite est un essai : elle vous montre ce qu’elle a trouvé pour que vous achetiez la version payante afin d’en enregistrer plus. RecovMe, PhotoRec et Windows File Recovery sont gratuits sans ce piège.

Les logiciels de récupération gratuits sont-ils sûrs ?

Téléchargez-les uniquement sur le site de leur éditeur. Un bon logiciel de récupération ne fait que lire le disque analysé et enregistre sur un autre disque : il ne peut donc pas écraser ce que vous voulez récupérer.

Les outils open source valent-ils les outils payants ?

Pour les fichiers supprimés et formatés sur cartes et disques, PhotoRec est très utilisé par les professionnels, et The Sleuth Kit est un outil d’analyse forensique de référence. RecovMe utilise les deux. Les applications payantes ajoutent des extras comme la copie de disque ou l’assistance, pas une autre forme de magie.

RecovMe est-il vraiment gratuit ?

Oui, à 100 %. Pas d’essai, pas de limite de taille, rien à débloquer après l’analyse. Il est open source, et les dons sont facultatifs.
