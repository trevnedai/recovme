Resposta curta

Não existe Recuva para Mac: o Recuva só roda no Windows. A maioria das páginas de “Recuva para Mac” recomenda depois um app pago cuja versão grátis para depois de algumas centenas de megabytes. O RecovMe é uma alternativa grátis e de código aberto para Macs com Apple silicon, sem limite de recuperação.

Escrito por Dhan Denvert Asuncion, criador do RecovMe. Os limites grátis foram conferidos no site de cada fabricante em 30 de outubro de 2026; veja os links na tabela.

O que quem usava o Recuva vai reconhecer

O charme do Recuva é o assistente simples: escolha o tipo de arquivo, escolha onde ele estava, escaneie. O RecovMe funciona do mesmo jeito em três telas: escolha o disco, escolha o que procurar e abra seus arquivos recuperados. Como o Recuva, ele traz de volta arquivos apagados recentemente com os nomes originais quando o disco ainda os tem. Diferente do Recuva, ele também faz uma busca profunda que encontra arquivos depois de uma formatação, e organiza fotos e vídeos pela data em que foram feitos.

Uma coisa que nenhum app de Mac consegue fazer

Todo Mac com Apple silicon criptografa o próprio disco e apaga sozinho os arquivos excluídos, então nenhum app, nem o RecovMe, consegue vasculhar o disco interno do Mac atrás de arquivos apagados. Para isso, use o Lixo, o Time Machine ou o iCloud. Apps de recuperação para Mac funcionam no que você conecta: cartões SD, pen drives e discos externos.

Perguntas

Existe um Recuva oficial para Mac?

Não. O Recuva é feito só para Windows, e não existe versão oficial para Mac. Downloads chamados de “Recuva para Mac” em outros sites não são o app oficial.

Dá para rodar o Recuva no Mac de outro jeito?

Não de forma útil. Uma máquina virtual com Windows não consegue ler o disco interno do Mac em baixo nível, e nos Macs com Apple silicon esse disco é criptografado de qualquer forma. Para cartões e discos externos, um app nativo de Mac é mais simples.

O RecovMe também roda no Windows?

Sim, no Windows 10 e 11 (64 bits), com os mesmos recursos.

O RecovMe é grátis mesmo?

Sim, 100%. Não há teste, nem limite de tamanho, nem nada para desbloquear depois da varredura. Ele é de código aberto, e doações são opcionais.
