# Security Policy

RecovMe reads whole drives and asks for administrator rights, so security matters a lot.
Thank you for helping keep it safe.

## Supported versions

Only the latest release gets security fixes. From version 0.3.0 on, RecovMe updates itself
(every update is signed, and RecovMe refuses updates that aren't).

## Reporting a vulnerability

Please **don't open a public issue** for a security problem.

Report it privately through GitHub: on this repository, open the **Security** tab and choose
**Report a vulnerability**. If that option isn't shown, open a normal issue that only says you'd
like a private contact for a security report, without any details, and you'll be contacted.

Please include what you found, how to reproduce it, and which version and system you used.
You'll get an answer as soon as possible, and credit in the release notes if you'd like it.

## Genuine copies

Official builds come only from [recovme.app](https://recovme.app) and the
[GitHub Releases page](https://github.com/trevnedai/recovme/releases). Each release lists
SHA-256 checksums in `SHA256SUMS.txt`, and the Mac app is signed with Developer ID
"Dhan Denvert Asuncion (GH6TUBY83F)" and notarized by Apple. If you find a copy that pretends to
be RecovMe, please report it too.
